# FastAPI ecommerce

Этот API предоставляет возможность управления категориями, подкатегориями, 
продуктами и отзывами в системе. Он позволяет получать список всех активных
продуктов, создавать новые продукты, а также получать продукты
по категориям и детальную информацию о каждом продукте.

## Описание проекта

### Функциональные возможности
Модели данных:
* Category(ссылается сам на себя для реализации иерархии категорий и подкатегорий)
* Product (связь с категорией и продавцом)
* Review (связь с продуктом и пользователем)
* User

### API:
* Полный CRUD для моделей продуктов, категорий и отзывов (без update).
* Реализован метод получения продуктов в категории и подкатегориях product_by_category.
* Метод получения отзывов об определенном товаре products_reviews и пересчет рейтинга по товару в add_review
* Аутентификация и авторизация: доступ к API только для активных 
  пользователей с разделением лоступа (is admin, is supplier, is customer).
* Документация API
